
# Kathmandu Valley PM2.5 Analysis Using Google Earth Engine

## Project Overview

This project analyzes spatial and temporal variations
in PM2.5 concentrations across Kathmandu Valley, Nepal.

The analysis uses Google Earth Engine (GEE), Python,
Xarray, and Geemap.

## Objectives

- Analyze daily PM2.5 concentrations.
- Examine monthly PM2.5 variations.
- Calculate annual PM2.5 averages.
- Visualize the spatial distribution of PM2.5.
- Export PM2.5 datasets for further analysis.

## Data Source

GHAP PM2.5 Dataset:

Daily:
projects/sat-io/open-datasets/GHAP/GHAP_D1K_PM25

Monthly:
projects/sat-io/open-datasets/GHAP/GHAP_M1K_PM25

## Tools and Libraries

- Python
- Google Earth Engine
- Geemap
- Xarray
- Xee
- Pandas
- Matplotlib

## Installation

Install the required libraries:

pip install -r requirements.txt

## Google Earth Engine Setup

1. Create or access a Google Earth Engine account.
2. Authenticate your account.
3. Initialize your registered Earth Engine project.
4. Run the notebook cells sequentially.
5. Draw the Kathmandu Valley study area using Geemap.

## Outputs

- Daily PM2.5 time series.
- Monthly PM2.5 analysis.
- Annual PM2.5 analysis.
- Spatial distribution maps.
- CSV data exports.
